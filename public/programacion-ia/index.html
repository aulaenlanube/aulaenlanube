Curso de Programación con IA

Aprender a programar con IA, no gracias a la IA. Una asignatura experimental donde el alumno dirige y la IA ejecuta: proyectos reales, código que sabes explicar, criterio propio.

Los dos proyectos del curso

1Proyecto individual — tu marca personal

Una web personal tuya: quién eres, qué haces, qué te gusta. Primera entrega esta misma semana (sesión 1). Es tu carta de presentación y tu primer despliegue real.

  • HTML + CSS + JS que tú controlas
  • Publicada en tu propio espacio de la web del curso
  • Evaluada por criterio: funciona + lo sabes explicar

2Proyecto en grupo — vuestra startup

Grupos de 4-5. Producto con base de datos, roles y entregas por sprints. Arranca en la sesión 3. El reto no es que "funcione con IA": es que funcione cuando tú no estás delante.

  • Producto con sentido + BD real (SQLite/Postgres)
  • Roles tipo startup + repositorio compartido
  • Revisado y defendido en clase
Norma de oro: usa todos los agentes IA que quieras —el del centro, los que tengas—, pero entiende cada línea que entregas. En la defensa oral la IA no te salva. El que dirige el código eres tú.

Sesiones

01

Tu web personal con IA — primer proyecto

17 sep 2026 · Crea HTML, CSS y JS desde cero con el chat del centro, paso a paso, con prompts listos para copiar. HOY 15:00
02

Mi web, versión 2 · Git

Mejoramos el diseño con un plan (no con suertes) y aprendemos a versionar el proyecto con Git. Tu historia de commits vale como evidencia. PRÓXIMAMENTE
03

Startup: producto con base de datos

Formación de grupos, idea, primer sprint. De la web estática a la aplicación con datos. PRÓXIMAMENTE
04

Despliegue: tu web en Internet

De tu carpeta a una URL pública con nombre. La web de tu marca, accesible desde cualquier sitio. PRÓXIMAMENTE

El temario se construye en clase, sin plan largo impuesto: experimentamos, documentamos y ajustamos cada semana. Esta guía la escribe el profesor y la podéis consultar siempre.
