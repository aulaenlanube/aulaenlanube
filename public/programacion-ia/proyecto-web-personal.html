Proyecto 1 · Web personal de marca · Toda la clase

Tu web personal, pieza a pieza

Primer proyecto del curso: una landing de marca personal. Es tu carta de presentación (y el primer paso para aprender a montar cualquier web), y lo construimos fichero a fichero con el chat del centro: entenderás cómo funciona una web por dentro antes de dejar que un agente la haga por ti.

Qué vas a construir

Una web real es una carpeta con ficheros que el navegador interpreta. El navegador lee primero el HTML (qué hay), lo viste el CSS (cómo se ve) y lo hace reaccionar el JS (qué hace). Eso es el trío:

index.html

Estructura y contenido. Qué hay en la página y en qué orden: encabezados, párrafos, imágenes, enlaces. El esqueleto, sin estilos.

style.css

Presentación. Colores, tipografías, espaciados, rejillas y versión móvil. No añade contenido: lo viste. Aquí la web se vuelve tuya.

script.js

Comportamiento. Lo que reacciona: menú en móvil, modo oscuro, contador de visitas… La página deja de ser un folio.

Cuando los proyectos crezcan llegará el cuarto elemento, la base de datos (guardar usuarios, partidas, pedidos): el corazón del proyecto de startup.

Anatomía de una web de marca personal

Una landing de marca responde en 10 segundos a quien llega. Cada bloque tiene una misión:

BloqueQué contieneQué responde
1 · Cabecera (hero)Tu nombre, una frase que te defina y una llamada a la acción («ver proyectos» o «contáctame»). Decide si siguen leyendo.¿Quién es este y por qué me importa?
2 · Sobre mí2-4 líneas: de dónde vienes, qué estudias, qué te motiva. Primera persona, sin postureo.¿Quién eres de verdad?
3 · Lo que he hechoPruebas: cursos, proyectos, deportes, colaboraciones. Hechos con contexto, no adjetivos.¿Qué sabes hacer?
4 · Me gusta3-6 cosas que te interesan (música, tech, videojuegos). Tu diferenciador; da pistas de cómo piensas.¿Qué te quema dentro?
5 · ContactoCorreo y enlaces (GitHub, LinkedIn). Sin fricción: un clic y apareces.¿Cómo te escribo?
6 · PieTu nombre, año, un detalle con personalidad.Cierre profesional.

Sesiones del proyecto

01

Crear tu web con el chat del centro

Primera sesión: pide tu HTML, tu CSS y tu JS con prompts que puedes copiar, únelos y publícala. Con checklist de entrega. YA DISPONIBLE
02

Versión 2: tu web mejor y compartida

Iteramos el diseño con un plan y aprendemos a trabajar con carpetas de proyecto como un profesional. PRÓXIMAMENTE
Importante: este proyecto es la base de todo lo demás. Lo que aprendas pidiendo, probando y corrigiendo aquí —el ciclo pensar → pedir → entender → mejorar— es exactamente lo que harás después con agentes de código, solo que a más velocidad.
